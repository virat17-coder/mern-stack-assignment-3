# Assignment 3 – JavaScript

## Question 1: Student Marks
JavaScript program using `forEach()`, `filter()`, `map()` and `reduce()` to display marks, find passing students, add grace marks and calculate the average.

## Question 2: Fetch Users from an API
Webpage that fetches users from JSONPlaceholder and displays their name, email and phone number in cards. It shows a loading message and handles errors.

## Run
- Open `index.html` in a browser.
- Run the marks program with `node student-marks.js`.
